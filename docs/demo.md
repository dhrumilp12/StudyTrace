# Demo and video notes

A final demo was produced on November 8, 2026: approximately **3 minutes 58 seconds**, 1920×1080, with synthetic male narration and captions. It is an **edited screen recording of real application interactions**, with crops, time compression, pause frames, and explanatory cards. It is not a continuous unedited session. An earlier still-based review cut was superseded and should not be described as the final video.

The final demo deliberately uses offline extraction, not live model inference. Recall attempts are scripted; self-ratings do not prove mastery or educational effectiveness. The export excerpt is a designed text screen based on an actual Markdown download. No invented click, inference, or download animation is claimed.

Video files, recordings, captures, narration, production scripts, exports, and private hosting identifiers are excluded from this source package. No public video link has been verified or added here. Review the final video before uploading it separately and add a verified public/unlisted link afterward if desired.

## Reproduce the demonstrated workflow

1. Run `npm run check`, then `npm start`. Use a disposable browser workspace.
2. Choose **Try a demo**, inspect the map and offline mode label, and open a source quote.
3. Enter practice. For the initial Plants card, deliberately enter “chloroplasts,” choose highest confidence, reveal, and mark it for review.
4. Inspect the confidence gap, retry that card with “Plants,” choose moderate confidence, reveal, and mark it recalled. Both attempts should remain in the trail.
5. Ask “What does chlorophyll absorb?” and inspect the matching excerpt. Ask “What is the capital of France?” and show abstention.
6. Export the study set and inspect the downloaded Markdown; reload to check persistence.
7. Explain optional local-model selection, visible fallback, unencrypted browser storage, and the absence of automated grading.

Verify actual behavior rather than narrating expected results over a failed interaction. See [validation](validation.md) for checks not completed.
