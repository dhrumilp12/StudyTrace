Offline mode

A deterministic extractive engine selects factual sentences and creates fill-in-the-blank cards. This is not a generative AI model.

Optional local AI

If Ollama is running on this computer with the configured model, it selects source passages and recall blanks. Every returned excerpt and answer must match the notes. Unverified output is replaced with extractive items. Your notes go only to the local Ollama endpoint.

Your data

Notes and progress are stored in this browser’s local storage, unencrypted. The local Node server processes requests without saving or logging notes. There are no analytics or external fonts. Don’t use sensitive notes on a shared computer.

Know the limits

Matching a source is not fact-checking. The notes can be wrong. Retrieval can miss relevant material or find an excerpt that does not fully answer your question. Progress reflects your own ratings, not a verified measure of mastery.
